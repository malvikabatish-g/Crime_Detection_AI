# AI Crime Detection - Model Development

## Overview
This repository contains the notebooks and trained models developed for an AI-based crime detection system. The project explores multiple transfer learning architectures for multi-class crime classification.

## Contents
- Data preprocessing
- Dataset preparation
- Model training
- Model evaluation
- Trained model files

## Models
- MobileNetV2 (TensorFlow/Keras)
- ResNet50 (TensorFlow/Keras)
- DenseNet121 (PyTorch)
- InceptionV3 (TensorFlow/Keras)
- EfficientNetB0 (TensorFlow/Keras)

## Dataset
The dataset contains six classes:
- Abuse
- Burglary
- Fighting
- Normal
- Road Accident
- Snatching

*The dataset is not included in this repository due to its size.*

## Requirements
- Python
- TensorFlow
- PyTorch
- OpenCV
- NumPy
- Pandas
- Scikit-learn
